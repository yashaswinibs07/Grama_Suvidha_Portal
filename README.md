# Grama Suvidha Portal

Grama Suvidha Portal is an Android application developed using Kotlin in Android Studio for managing village-level public services digitally.

## Features
- Citizen service management
- Complaint registration
- Service request tracking
- Firebase database integration
- User authentication
- User-friendly interface

## Technologies Used
- Kotlin
- Android Studio
- Firebase
- MVVM Architecture

## Modules
- Login System
- Complaint Module
- Service Request Module
- User Dashboard
- Firebase Integration

## Project Structure
- app
- gradle
- Kotlin source files
- XML layouts
- Firebase configuration
